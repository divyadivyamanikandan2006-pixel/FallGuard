# FallGuard – Smart Patient Fall Detection System

## 📌 Overview

FallGuard is a smart wearable-based patient fall detection system designed to detect sudden fall conditions and provide an alert for quick assistance.

The system uses motion sensing technology to monitor movement and identify abnormal fall conditions. It is developed as an embedded and IoT-based healthcare safety prototype.

## 🎯 Objective

The main objective of FallGuard is to develop a compact and practical system that can detect a patient's fall condition and generate an alert when a fall is identified.

## ⚙️ Working Principle

1. The system is powered using an external power supply.
2. The MPU6055 motion sensor monitors the movement of the user.
3. The ESP32 processes the motion information.
4. When a fall condition is detected, the system activates an alert.
5. The LED and buzzer provide local indication of the detected condition.
6. Blynk is used as part of the IoT-based monitoring setup.
